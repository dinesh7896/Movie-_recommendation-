# Movie-_recommendation-
This project focuses on building a Movie Recommendation System that suggests movies to users based on their preferences. The system uses data preprocessing, feature extraction, and similarity techniques to recommend relevant movies.

# # Movie Recommendation System

## Description
A machine learning project that recommends movies based on user preferences.

## Technologies
- Python
- Pandas
- Scikit-Learn
- EDA

## Features
- Personalized recommendations
- Content-based filtering
- Interactive UI
